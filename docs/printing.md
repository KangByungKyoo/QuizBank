# 문제 출력 및 PDF 저장

`문제` 탭의 `문제 출력`에서 A4 문제지와 정답·해설지를 생성합니다. 외부 서버, 유료 API, 저장소 전체 접근 권한, 새 라이브러리는 사용하지 않습니다. 기존 Room 스키마와 마이그레이션, 문제 등록·시험·학습 기록 처리에는 변경이 없습니다.

## 사용 방법

1. 카테고리를 복수 선택하거나 전체로 두고 하위 카테고리 포함 여부를 지정합니다.
2. 전체/객관식/단답형/OX, 10/20/50/전체 문제, 등록/무작위 순서를 선택합니다.
3. 정답지·해설 포함 여부와 단답형 답안 공간 1~3줄을 지정합니다. 기본값은 정답지 ON, 해설 ON, 답안 1줄입니다.
4. 미리보기에서 문제지와 정답·해설지의 모든 페이지를 확인합니다. 확대 상태에서는 가로로 이동할 수 있습니다.
5. PDF 저장 또는 인쇄에서 원하는 문서를 선택합니다. 두 문서는 각각 저장/인쇄하며, 저장 위치와 파일명은 Android 파일 선택기에서 변경합니다.
6. 저장 성공 안내의 `열기`로 설치된 PDF 뷰어를 사용할 수 있습니다.

설정을 바꾸기 전까지 확정된 선택을 재사용하므로 무작위 순서도 미리보기, 저장, 인쇄에서 일치합니다. 같은 설정에서 새로 뽑으려면 `문제 다시 선택하기`를 누릅니다. 회전이나 미리보기 왕복에서도 선택은 유지됩니다. 운영체제가 앱 프로세스를 종료하면 출력 설정과 임시 선택은 다시 생성해야 합니다. 기존 DB의 문제·학습 기록은 영향을 받지 않습니다.

- `navigation/BankViewModel.kt`: PRINT/PRINT_PREVIEW 경로, 돌아가기 규칙, 수명 주기가 유지되는 출력 컨트롤러 추가.

## PDF 생성 구조

`BankRepository.snapshot()` → `PrintSelector` → `PrintSelection` 하나 확정 → 문제지 및 정답·해설지 생성 → 앱 캐시의 생성본 미리보기/SAF 저장.

시스템 인쇄는 같은 선택을 바탕으로 벡터 PDF를 생성하며 지정된 용지·여백 안에 같은 A4 배치를 비율에 맞춰 놓습니다. 페이지 범위를 선택하면 해당 페이지들만 전달합니다. 인쇄의 문제 번호·페이지 꼬리말은 원본 문서의 번호를 유지합니다.

- A4: 595×842 PDF 포인트, 세로, 흰 바탕/검정 글자, 본문 10.5pt, 제목 18pt, 사방 약 12.7mm 여백.
- Android `PdfDocument`/`Canvas`와 `StaticLayout`을 사용합니다. 기기의 한글 폰트가 PDF에 포함되며 별도 폰트 다운로드가 필요 없습니다.
- 문제지는 이름·날짜란, 객관식 보기, O/X 표시, 단답형 답안선을 제공합니다.
- 일반 문제와 답안 공간은 한 페이지에 함께 배치합니다. 한 페이지보다 긴 문제만 `(계속)`으로 넘기며 마지막 부분과 답안 공간을 함께 배치합니다.
- 정답 표는 해설 OFF일 때 2열, ON일 때 3열이며 미등록 해설은 `해설 미등록`으로 표시합니다. 긴 행은 다음 페이지로 이어지고 표 머리글이 반복됩니다.
- 등록 순서는 `createdAt`, 동률이면 ID로 정렬합니다. 무작위는 후보를 중복 제거한 뒤 한 번 섞어 선택합니다.
- 기존 시험의 단답형 제한을 바꾸지 않고, 출력에서는 저장된 세 유형을 모두 지원합니다. 내용·카테고리·정답이 완성되고 유형별 검증이 통과한 문제만 후보가 됩니다.
- PDF 생성과 파일 저장은 IO 디스패처에서 수행하며 오류를 사용자에게 표시합니다. 파일 선택 취소는 오류로 취급하지 않습니다.
- 캐시 PDF는 DB와 분리되어 있으며 Android의 앱 캐시 관리 대상입니다.

## 검증 및 한계

빌드 명령:

```powershell
./gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:connectedUiTestAndroidTest --offline
```

검증 범위:

최종 실행 결과: 디버그 빌드 성공, 단위 테스트 28개와 실기기 계측 테스트 18개 전부 통과. 실기기 계측 테스트에는 기존 앱 흐름·저장소 회귀 테스트와 새 출력 테스트 4개가 포함됩니다.

- 단위 테스트: 카테고리·하위 포함·복수 선택·세 유형·등록 순서·무작위 중복 제거·문제 수·미완성 데이터·빈 결과.
- Galaxy S24+ / Android 16 실기기: 10문제와 60문제 PDF 생성, A4 크기, 세 유형, 한글·영문·특수문자, 표의 해설 ON/OFF, 1페이지보다 긴 문제·보기·해설의 마지막 표식, 페이지 번호.
- Android PdfRenderer로 생성 PDF의 모든 테스트 페이지를 다시 열어 렌더링하고 텍스트를 검사합니다. 문서 PNG와 화면 캡처는 connected test 추가 출력 폴더에 저장됩니다.
- 미리보기에서 정답 문서 전환, 화면 왕복 시 선택 재사용, 정답지 제외, URI 저장 바이트 일치, 취소, 저장 실패 안내, Room 데이터 보존.
- Android 시스템 파일 선택기로 실제 저장한 PDF를 ContentResolver로 다시 열어 원본 바이트와 비교합니다. 테스트가 만든 시스템 파일은 검증 후 제거합니다.
- Android 시스템 인쇄 화면의 A4 미리보기 표시를 검증합니다. 실제 프린터로 종이에 출력하는 것은 별도 확인이 필요합니다.

실제 프린터 및 Android 8~15 기기의 제조사별 인쇄 서비스, 저장 공간이 물리적으로 소진된 상태, 프로세스 강제 종료 도중 저장은 별도 실환경 검증이 필요합니다. 저장 실패 경로는 존재하지 않는 대상 URI로 검사합니다.

향후 개선: 출력 설정의 프로세스 종료 후 복원, 페이지 썸네일과 직접 페이지 이동, 더 많은 용지 규격·표 스타일, PDF 생성 취소 버튼, 캐시 파일 보관 기간 관리.

공식 API 참고: [Android custom printing](https://developer.android.com/training/printing/custom-docs), [PdfDocument](https://developer.android.com/reference/android/graphics/pdf/PdfDocument), [PdfRenderer](https://developer.android.com/reference/android/graphics/pdf/PdfRenderer).
